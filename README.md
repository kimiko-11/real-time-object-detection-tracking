# Real-Time Object Detection and Tracking

A real-time computer vision pipeline for detecting, tracking, and analyzing object motion using YOLOv8 and OpenCV.

The system performs:

• Real-time object detection  
• Multi-object tracking with persistent IDs  
• Trajectory visualization  
• Simple motion prediction  

This project demonstrates a basic perception pipeline similar to those used in robotics and autonomous systems.

---

## Features

- Real-time object detection using YOLOv8
- Multi-object tracking across frames
- Trajectory path visualization
- Simple motion prediction based on object velocity
- Webcam-based real-time processing

---

1. Clone the repository

2. Navigate to the project folder

3. Install dependencies


The system will open your webcam and perform real-time detection and tracking.
